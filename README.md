# Laboratoires de cybersécurité et réseaux

**Aminata Ba** · Licenciée en Ingénierie des Réseaux Informatiques et Télécommunications (IPTMA, Bamako, 2026)
Ancienne stagiaire en cybersécurité à l'AGETIC (Mali).

Ce dépôt rassemble mes travaux pratiques en sécurité des réseaux et des systèmes d'information. Tous les tests ont été réalisés dans des **environnements virtualisés isolés**, sans jamais viser de systèmes réels.

## Projets

| # | Projet | Thèmes | Outils |
|---|--------|--------|--------|
| 01 | [Déploiement de pare-feu open source et durcissement réseau](01-pare-feu-pfsense-ipfire/) | Segmentation réseau, filtrage de paquets, zones de sécurité | pfSense, IPFire |
| 02 | [Simulation d'attaque par force brute sur Windows](02-simulation-force-brute-windows/) | Authentification, gestion des mots de passe | Kali Linux, outils de tests d'intrusion |
| 03 | [Sécurité multicouche : la défense en profondeur](03-defense-en-profondeur/) | Analyse des risques, couches physique / réseau / système / application | Mémoire de licence en équipe de quatre (16,5/20) ; audit, VLAN, pfSense, OpenLDAP, application LogiTrans |

## Compétences

- **Réseaux** : TCP/IP, DHCP, DNS, VLAN, routage et commutation
- **Systèmes** : Linux (Debian, Kali), Windows Server
- **Sécurité** : pare-feu, contrôle d'accès, durcissement, défense en profondeur, bases du test d'intrusion
- **Programmation** : Python, C, C++, SQL
- **Outils de laboratoire** : GNS3, EVE-NG, VMware Workstation

## Éthique

Les simulations d'attaque sont menées uniquement sur des machines virtuelles qui m'appartiennent, dans un réseau isolé. Aucune donnée réelle, adresse réelle ou identifiant réel n'est publié ici.
